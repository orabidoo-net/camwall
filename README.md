# camwall
Webcam-Wallpaper für Linux
Mit Camwall kannst Du beliebeige live-Webcam-Streams aus dem Internet als Wallpaper für Deinen Linux-Desktop anzeigen lassen. Es ist möglich bis zu 2 Bildschirme mit je einem Stream zu versehen. Eine Aufnahmefunktion und eine Verwaltung der Streams, sowie der AUfnahmen ist enthalten.
